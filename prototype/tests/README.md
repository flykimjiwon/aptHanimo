# 프로토타입 검증

저장소 루트에서 실행한다. Node 18 이상, 외부 패키지는 필요 없다.

```sh
node prototype/tests/run.mjs
node --test prototype/tests/harness.test.mjs
```

`run.mjs`는 실제 월드·경로 함수를 VM에서 실행해 149개 규칙·데이터·골든 기준을 검사한다. 기본 실행은 `golden.json`을 만들거나 갱신하지 않는다. 누락·JSON 손상·단지/지표 누락·잘못된 oneway/odir는 실패한다.

원자료나 계산 규칙을 의도적으로 변경했을 때만 전체 차이를 검토한 뒤 `node prototype/tests/run.mjs --update`를 실행한다. 모든 규칙·데이터 검사가 통과해야 골든을 쓴다. 골든값은 게임 모델의 회귀 기준이며 실제 측량값이 아니다.

`harness.test.mjs`는 검증기 자체의 11개 동작을 확인한다. 정상 입력, 골든 누락·손상·빈 지표·일부 지표 누락, 방향 데이터 누락·길이·범위 오류, 실패한 갱신의 원본 보존, 명시적 기준 생성과 재검사를 포함한다. 테스트가 만든 임시 fixture 파일만 정리한다.

`bash prototype/tools/bake.sh`는 셀 재굽기 → 본편·스타일랩 생성 → 위 두 검사를 순서대로 실행한다. `tools/osm3.json`이 없거나 `--refresh`를 주면 네트워크에서 원자료를 받는다. 원자료와 골든을 백업·검토한 뒤 사용한다. 스타일랩 HTML을 직접 수정하지 않는다.

2026-10-12 후속 수정에서 재굽기 후 누락됐던 스타일랩 crop을 갱신했다. 격리된 기존 데이터로 전체 파이프라인을 실행해 생성물 7개 일치, 원본 셀·골든 불변을 확인했다. 브라우저 두 HTML × 390/1440/1920px × light/dark의 12조건에서 실제 crop과 셀 데이터의 일치, 오류·문서 가로 넘침 0을 확인했다. 실제 기기 검증이나 전체 접근성 인증은 아니다.
