# 위성·거리뷰 대조 기록

확인일: 2026-10-11. 촬영일과 확인일은 다르다. 각 지도 서비스 화면의 최신 표시 상태를 확인했으며 모든 사진의 실제 촬영 시점까지 확인한 것은 아니다.

| 단지 | 직접 확인한 이미지 | 관찰하고 구현에 반영한 내용 |
| --- | --- | --- |
| 하이베르 | `haiver-satellite.png`, `haiver-street.png` | 서쪽 날개와 동쪽 길게 늘어선 동 배치, 불규칙한 15개 동 윤곽. 거리뷰의 흰색·연회색 외벽과 어두운 측면 패널을 색과 매스로 단순화했다. |
| 왕십리자이 | `xi-satellite.png`, `xi-street.png` | 하이베르 남동쪽, 굽은 외곽 도로를 따라 놓인 7개 동 배치. 밝은 외벽과 어두운 출입 문주를 관찰했으며 문주 위치·폭은 검증된 geometry로 수집하지 않아 실제 출입구로 만들지 않았다. |
| 라체르보 | `cherbo-satellite.png`, `cherbo-street.png` | 위성 배경은 공사 시점 흔적이 남아 있어 최신 지도상의 7개 동 polygon을 우선했다. 거리뷰에서는 완성된 회색·흰색 탑상 건물과 큰 GATE 1 문주를 확인했다. 건물 윤곽을 반영했으며 문주나 내부 조경은 실측 재현하지 않았다. |

원문: [하이베르 호갱노노](https://hogangnono.com/apt/31af), [왕십리자이](https://hogangnono.com/apt/aEc43), [라체르보](https://hogangnono.com/apt/e8Q5e).
거리뷰: [하이베르 네이버 장소](https://map.naver.com/p/entry/place/18705765), [왕십리자이 네이버 장소](https://map.naver.com/p/entry/place/35689784), [라체르보 네이버 장소](https://map.naver.com/p/entry/place/1371782088).

사진은 배치와 건축 색감의 교차 확인에 사용했다. 게임 텍스처로 사용하거나 사진측량으로 3D 복원하지 않았다. 창문 반복 패턴, 나무, 꽃, 캐릭터, 실내 공간은 자체 제작한 시각적 표현이며 실제 시설 조사가 아니다. 건물 높이와 도로 폭의 추정 구분은 QUALITY.md 및 개별 JSON `heightSource`·`sources`를 따른다. 사진 파일은 로컬 조사 근거로 보존하고 배포 앱의 `public/`에는 포함하지 않는다.
