총 36장. 라체르보는 외부·단지 공간 10장과 공식 공용 라운지 내부 1장이다. 조감도·CG·모형·주변 다른 단지·개인 세대 내부 사진은 수에 넣지 않았다. 사진의 촬영일을 확인하지 못한 경우 `shotDate: null`이며 업로드 날짜를 촬영일로 바꾸지 않았다. 파일 해시 중복 여부와 피사체는 각각 확인했다. 같은 위치의 다른 각도는 별도 사진으로 기록하되 단순 해상도 복제는 별도 참고로 세지 않는다.

## 공식 브랜드 파일

[공식 이미지 원장](official/manifest.json)에 출처 페이지·이미지 URL·원본 크기·SHA-256·화면에 사용하는 영역을 기록했다. 파일 자체는 원본 바이트를 보존하며 런타임에서 해당 표기 부분을 잘라 그린다.

- 래미안: 현장 사진에 남아 있는 삼선·來美安 구형 표기를 공식 BI 변경 소개 이미지에서 사용한다. [2026년 새 BI 설명](https://www.raemian.co.kr/brand/symbol/symbol.do)을 하이베르 전체 교체의 증거로 해석하지 않는다.
- 자이: 현장 문주의 곡선 Xi와 맞는 공식 보존 시그니처를 사용한다. 최신 각진 로고 이미지는 비교 자료다.
- 라체르보: [공식 단지 사이트](https://www.prugio.com/lacervo/)의 SUMMIT PRUGIO 표기를 사용한다.
- 아이파크: [공식 BI](https://www.i-park.com/brand/brand-design)를 확장용으로 수집했다. 현재 세 단지 중 하나를 아이파크로 바꾸지 않았으며 아이파크 실존 단지의 사진 10장 조사를 완료했다는 뜻도 아니다.

## 구현과 해석의 경계

`src/architecture/profiles.ts`는 실제 단지 ID와 관찰한 색·창 비례·기단·세로 리듬을 연결한다. Three 월드와 Canvas 실험실이 같은 프로필을 사용한다. 건물 10종은 표현 매체 차이를 유지하면서 실제 단지 고유색을 반영한다. 정적 건물 썸네일은 동일한 예시 외곽선으로 기법을 비교한다.

지리 외곽선, 동 수, 도로, DEM, 거리와 경로 시간은 사진 스타일 변경과 분리했다. 사진에서 본 정문·선큰·식재의 정확한 좌표가 확보되지 않아 새로운 실측 시설물로 배치하지 않았다. 크라운, 로고의 부착 면과 크기, 기단 높이, 창 수는 게임용 추정 표현이다. 모든 동을 포토그래메트리로 복원한 결과가 아니다. 실내는 기존 구조 시연을 유지하며 사진처럼 내부 전체를 재현했다고 주장하지 않는다.

외부 사진은 조사 폴더에만 저장했으며 게임 표면에 사진을 텍스처로 붙이지 않았다. 원본 사진과 로고의 상업 재배포 허락을 얻었다는 주장은 하지 않는다. 브랜드 제휴·공식 서비스 표기도 없다.
