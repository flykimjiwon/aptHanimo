## S6 · V2 실제 공간 자료와 자체 체험 모델

파일:

- `src/graph.ts`
- `src/routes.ts`
- `src/scene/terrain.ts`
- `src/scene/interior.ts`
- `src/complexes.ts`
- `src/data.ts`

모델 성격:

- V2 지상은 `public/worlds/{haiver,xi,cherbo}.json`의 실제 WGS84 좌표를 단지 중심 기준 로컬 미터로 투영한다. 동쪽 +X, 북쪽 -Z, 1단위=1m이다. `graph.ts`의 과거 공통 지상 모형 좌표는 V2 지상 렌더링·길찾기에 사용하지 않는다.
- 코어 동 외곽선은 호갱노노 공개 polygon 응답, 주변 건물과 도로·보행로·계단 선형은 OpenStreetMap, 지면은 SRTM 기반 Terrarium DEM을 사용한다. 출처·해시·누락은 [공간 품질 기록](spatial/QUALITY.md), 실제 위성·거리뷰 대조는 [사진 관찰 기록](spatial/PHOTO_OBSERVATIONS.md)에 있다.
- 지형은 30m SRTM 원자료를 65×65 격자로 재표본화한 광역 높낮이다. 건물 높이와 도로 폭은 확인된 태그와 렌더 추정치를 구분한다. 개별 출입구·문턱·경사로·통행 허가는 미확인이다.
- V2 경로 길이는 실제 로컬 좌표 사이에서 계산한다. 이동 속도와 ETA는 게임 체험 추정이다. 출처 페이지에 적힌 역·학교 거리와는 별도 값이다. POI가 건물 중심 등에 있으면 확인된 인근 길까지만 안내하며 출입구를 임의로 만들지 않는다.
- 창문 반복, 조경 나무·꽃, 캐릭터와 동행은 자체 제작한 연출이다. 실제 창호·식재 조사가 아니다.
- 지하 레이어는 개념적 cutaway이며 실제 지하 층수나 구조를 주장하지 않는다.
- 커뮤니티/운동 공간은 공식 공고로 존재 근거를 확인한 범위와, 체험용으로 만든 배치를 분리한다.
- 학교 마커는 가까운 학교 표시이며 통학구역 또는 배정을 보장하지 않는다.
