## 발견하고 수정한 문제

1. 커뮤니티 순간이동 뒤 자동차·자전거 복원: 레이어가 정한 도보 모드를 유지한다.
2. 일반 지면 경로 완료가 오래된 `home` 등을 새 도착으로 알림: named 경로만 실제 목적지 이벤트를 발생시킨다.
3. 지도 시작위치 선택을 켠 뒤 다른 장소 선택에도 무장 상태 유지: picker·장소·홈·레이어·모드 변경 등에서 취소한다.
4. 작은 라체르보 공원/놀이터 3개가 거친 지형 정점에 걸리지 않음: 실제 OSM 다각형을 별도 저비용 DEM 오버레이로 그린다.
5. 스타일 모달의 닫힌 상태에 flex 표시가 덮어씀: `[open]`에서만 스타일 모달 표시 규칙을 적용한다.
6. 큰 행동 모듈: 프레임 순서와 프리셋 상수를 분리해 World249줄, 스타일 UI219줄로 줄였다.

## 남은 실제 브라우저 검사

Ego TaskSpace53은 호갱노노 위치 권한 창에서 사용자 제어로 넘어갔다. 사용자가 권한 창을 처리하고 제어 반환을 확인하기 전까지 해당 공간·새 공간·다른 브라우저로 우회 조작하지 않았다. V4와 V5 화면 QA는 통과로 표시하지 않는다.

권한 반환 후 필요한 시나리오:

- PC1280×800, 모바일390×844: 스폰 → 자유 이동 → 스타일 열기/닫기 → 7프리셋 → 개별10/11/11 선택 → 3시점 → 원래 조합 복귀.
- 휠·핀치·드래그·회전·따라가기: 손가락 하나를 뗀 핀치가 의도치 않은 이동으로 바뀌지 않는지 확인.
- 1/2/4/8/16배속에서 수동/경로 이동·충돌·도착, 입력을 놓으면 정지.
- 장소 순간이동·지도위치 순간이동·불가 지점·취소·다른 POI 선택 후 보통 탭 이동 복귀.
- 가족·유모차·차량·건물 가림·밤·성능 모드, 세 단지·실내외 전환.
- 두 브라우저 실제 접속자, 수첩 작성/저장/재방문/내보내기, 조합 URL/저장소 접근 제한.
