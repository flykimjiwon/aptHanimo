# V5 런타임 감사

2026-10-12. 브라우저 화면 검증을 대체하지 않는 엔진·서비스 실행 기록.

## H1: 표현 전환이 공간·경로 또는 자원 소유를 손상시킬 수 있다

세 실제 월드 ×11건물+11지도=66개 terrain을 구성·폐기하고 원본 데이터 직렬화·재료 소유를 비교했다. 공간 변경0, geometry46,269/46,269·material86,727/86,727·texture42/42 폐기 일치. 이동 중 XI 드라이버의 위치·route 거리·시간·moving 상태가 유지됐다. 카메라와 스타일/동작 경계는 전체74개 테스트에 포함된다. 가설의 검사 범위에서는 손상 없음. 실제 GPU 회수와 렌더 결과는 브라우저 재검증 필요.

## H2: 순간이동·익명 경로 완료가 잘못된 상태 전이를 만들 수 있다

커뮤니티 car/bike→walk 회귀, XI named/point 경로 실제 엔진 완주, 모든 월드23개 알려진 장소의 car 착지 passability와 지도 unsafe point 거부를 검사했다. 커뮤니티 모드 강제 복원과 오래된 home 도착 이벤트가 발견되어 수정됐다. 지도 picker로 바꾼 뒤 무장 상태가 남는 분기도 수정했다. 회귀 테스트 통과. 실제 DOM 포인터/모바일 터치 경로는 아직 미검증.

## H3: 빌드가 성공해도 실제 서버 자산/접속자 통신은 실패할 수 있다

`bun start`로 떠 있는 localhost5178에 실제 HTTP·WS 요청을 보냈다. 파일31개 검사(오류 응답 포함), 생성된 파일과 응답 바이트 일치, 두 WS 클라이언트의 위치 동기화·세 번째 별도 방 격리·잘못된 위치1008종료를 확인했다. 결과는 `runtime-assets.json`에 저장했다.

첫 CLI 검사기는 메시지 type을 임의로 `position`으로 보내 timeout됐다. 실제 `src/protocol.ts` 계약은 `move`였고 서버가 잘못된 메시지를 거부한 정상 결과였다. 검사기를 계약에 맞게 수정한 뒤 통과했다. 이 과정에서 제품 프로토콜을 느슨하게 바꾸지 않았다.

## H4: CSS/소형 지형은 자동 엔진 검사에서 빠질 수 있다

소스 검토로 닫힌 dialog를 표시하는 `:has` 규칙을 찾고 `[open]`로 한정했다. 라체르보 작은 OSM 면3개는 65×65 지면 정점에 안 걸려 안 보였고 실제 폴리곤 DEM 오버레이로 수정했다. 면마다 삼각형이 존재·DEM+0.035m·위쪽 법선을 유지하는 회귀를 추가했다. CSS의 실제 시각 결과는 여전히 브라우저 확인이 필요하다.
