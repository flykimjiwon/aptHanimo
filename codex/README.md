# 한바퀴 · Codex V5

실제 서울 단지 주변을 자유롭게 걷는 브라우저 산책 프로토타입. **래미안신당하이베르·왕십리자이·라체르보푸르지오써밋** 세 단지를 구현했다. `aptHanimo/codex/`의 독립 앱이며 저장소의 `prototype/` Claude 버전은 별도 구현이다.

## 실행

```sh
bun install --frozen-lockfile
bun run build
bun start
```

[본편](http://localhost:5178/) · [스타일 실험실](http://localhost:5178/style-lab.html). 휴대폰은 같은 Wi-Fi에서 실행 컴퓨터의 LAN IP와 `:5178`로 접속한다. `bun run dev`는 Vite UI 개발 서버이며 접속자 공유용 `/presence` WebSocket은 `bun start`가 제공한다. GitHub에 소스를 올린 것과 웹 서비스를 공개 배포한 것은 다르다.

## 현재 구현

- 실제 좌표·동 외곽선·OSM 도로·SRTM 고도를 쓰는 단지 중심 1.3km 월드 3개.
- WASD·방향키·조이스틱·탭 길안내, 도보·유모차·자전거·자동차, 혼자·커플·가족.
- **캐릭터10 / 건물11 / 지도11 / 평면·2.5D·원근3D 시점**, 프리셋7개·조합 저장·공유 링크.
- 여섯 입체 캐릭터와 네 방향별 아틀라스. 실험실은 캐릭터·건물·지도 각10종 비교를 유지한다.
- **1·2·4·8·16배속**, 기본2배, 연속 줌·핀치·카메라 따라가기·밤·성능 절약 모드.
- 장소별 순간이동과 **지도에서 직접 시작 위치 선택**, 충돌/차량 도로 규칙과 DEM 높이 적용.
- 사진36장을 참고한 3단지 입면·공식 브랜드 표기, 고도 음영·DEM 기단·실제 공원23면과 라체르보 지상 선로30선.
- 같은 서버·단지·방의 실제 WebSocket 접속자, 장소 수첩 저장/내보내기.
- **수첩 검색·단지 필터·기록 수정·저장 장소 지도 선택**, 이전 체크 항목 보존·삭제 확인·저장 실패 보호.
- 서울25개구 단지 도감 2,893공개 레코드와 2026-09-28~10-04 주간 관심250건.

커뮤니티·지하 주차장은 실제 평면도가 없는 **구조 예시**다. 광고는 명시적인 데모이며 상용 광고망·과금·추적은 연결하지 않았다. 커플·가족은 한 사용자의 동행 연출이고 실제 접속자 수는 서버 연결로만 표시한다.

## 자료 해석

1단위=1m, 동쪽+X·남쪽+Z. 코어15/7/7동 외곽선과 주변 OSM 자료를 사용했다. DEM은 SRTM30m 원천을 65×65로 재표본화한 것이며 높은 측정 해상도나 정밀 접근성 지도를 뜻하지 않는다. 건물 높이·길 폭에는 추정값이 있다. 사진·위성 캡처는 사람의 관찰 근거이고 제품 사진 텍스처로 넣지 않았다. 외곽선 공개/상업 재사용, 공식 마크, 원본 사진의 권리는 각 출처에 남으며 브랜드 제휴를 의미하지 않는다. OSM은 © OpenStreetMap contributors / ODbL1.0 출처를 유지한다.

공개 체크아웃은 생성된 공간 JSON과 앱 자산으로 실행된다. 연구 사진 원본·지도 캡처·임시 API 응답은 로컬 인계 자료에 보존하며 Git에는 넣지 않는다. 수집 스크립트를 재실행하려면 필요한 원자료/API 접근을 별도로 갖춰야 한다. 도감의 2,893개 레코드가 모두 플레이 월드로 구현되었다는 뜻은 아니다.
