# 한바퀴 단지 섬 · 별도 개선판

2026-10-12. 사용자 요청: 기존 버전을 유지하면서, 실제 단지 지도와 위성 사진을 참고한 **공중에 떠 있는 게임 속 섬**으로 정리한다. 첫 대상은 왕십리자이다.

## 실행과 비교

```sh
bun install --frozen-lockfile
bun run build
bun start
```

- 개선판: [단지 섬](http://localhost:5178/island.html)
- 기존판: [실제 생활권 산책](http://localhost:5178/?complex=xi)
- 스타일 실험실: [기존 실험실](http://localhost:5178/style-lab.html)

개선판은 별도 HTML 진입점·`src/island/`·CSS를 쓴다. 기존 본편의 코드·지도 JSON·저장 키는 수정하지 않는다. Vite 입력에 `island.html`을 추가했기 때문에 산출 청크 이름은 바뀔 수 있다. 개선판은 브라우저 저장소에 쓰지 않는다.

## 어떤 모습과 조작인가

원형 받침을 없애고, 단지 지도 응답의 불규칙한 윤곽으로 땅을 잘라냈다. 위에 실제 위치·외곽선을 가진 101~107동을 놓고 아래에는 얇은 테두리·흙층·좁아지는 단면과 부드러운 그림자를 만든다. 주변 수백 동은 그리지 않는다. 첫 화면은 단지 전체와 소수의 조작만 보여주며, 동 번호를 누르면 세부 화면이 열린다.

- **초록 정원 / 살구빛 점토 / 파란 저녁**: 같은 배치에 적용하는 세 가지 재질·조명 팔레트.
- 드래그 회전, 휠·핀치 확대, 회전·확대·축소 버튼. 전체 보기와 북쪽을 위로 보는 시점.
- 동 번호 선택·가까이 보기·전체 복귀.
- 친구와 산책 시작/정지, WASD·방향키·터치 방향 버튼, 바닥을 눌러 이동. 모형 산책은 약4배속이며 실제 도보시간 안내가 아니다.
- 섬 밖과 건물 내부로 이동할 수 없다. 1.7배로 표현한 캐릭터에 맞춰 외곽/건물에서1.8m 여유를 둔다. 좁은 통로를 보존하기 위해 확대는 카메라로 제공한다.

## 실제 자료와 연출의 경계

| 요소 | 기준 |
|---|---|
| 단지 윤곽 | 기존 `research/spatial/xi-hogang-polygon.json`의 `groupPolygons`. 기존 수집기와 같은 111,320m/도·위도 cos 투영으로 변환한 27점. 지적 측량 경계로 보증하지 않음 |
| 건물7개 | 기존 `public/worlds/xi.json`의 core 외곽선과 동 번호·위치. 입력 불변 |
| 도로/보행로 | 기존 OSM 선형을2m 이하로 나눠, 폭까지 섬 안에 들어가는 부분만 표시. © OpenStreetMap contributors / ODbL1.0 |
| 위성 대조 | 2026-10-12 [네이버 왕십리자이 위성 화면](https://map.naver.com/p/entry/place/35689784?c=18.00,0,0,2,dh)을 직접 확인. 북쪽101·102동, 남쪽105·106·107동, 굽은 동쪽 길과 중앙 마당을 대조. 촬영일 미확인 |
| 높이 | 모형의 가독성을 위해 건물0.55배, 기존 SRTM 지형0.35배. 원래 높이 자료를 변경하지 않음 |
| 수목·창문·색·단면 | 절차적 연출. 실제 나무 위치·창 개수·지층·시설 조사값이 아님 |

위성 캡처를 텍스처로 붙이거나 공개 앱 자산에 포함하지 않았다. 평면 위치를 보존한 시각적 모형이며 사진측량으로 재구성한 정밀3D가 아니다. 출처와 표현 차이는 화면 아래 **어디까지 실제 모습인가요?**에도 안내한다.
