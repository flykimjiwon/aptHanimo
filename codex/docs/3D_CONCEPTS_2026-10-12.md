# 귀여운 3D 컨셉 선택과 본편 연결

2026-10-12. 사용자의 우선순위는 **실제 사용성, Three.js 3D, 귀여운 캐릭터, 여러 디자인 풍**이다. 수첩 개발 다음 작업으로 본편의 스타일 선택과 입체 캐릭터를 보강했다.

## 사용하기

`bun run build && bun start`로 실행하고 본편의 **스타일**을 누른다. 컨셉 그림을 고르면 모형과 현재 산책 중인 동네가 함께 바뀐다. 좌우 회전·정면 버튼 또는 가로 드래그로 캐릭터를 살펴보고, **이 모습으로 산책하기**로 돌아간다. 걸음 보기는 직접 켜고 끌 수 있다.

| 컨셉 | 캐릭터 | 건물 / 지도 | 시점 |
|---|---|---|---|
| 포근한 마을 3D | 동글 친구 | 부드러운 건물 / 파스텔 마을 | 원근 3D |
| 말랑 점토 3D | 봉제 친구 | 점토 / 장난감 섬 | 원근 3D |
| 복셀 3D | 블록 친구 | 픽셀 블록 / 격자 | 원근 3D |
| 종이 2.5D | 종이 캐릭터 | 종이 건물 / 종이 레이어 | 등각 |
| 잉크 2D | 잉크 캐릭터 | 선화 건물 / 노트 | 평면 |
| 수채화 2.5D | 새싹 친구 | 수채화 건물 / 공원 | 등각 |
| 현장풍 3D | 동글 친구 | 현장 재료감 / 실제 동네 지도 | 원근 3D |

처음 방문할 때는 포근한 원근 3D로 시작한다. 저장한 스타일과 URL 선택이 우선한다. 직접 조합을 열면 기존 캐릭터10·건물11·지도11·시점3을 따로 고를 수 있다. 휴대폰에서는 미리보기 아래로 스크롤해 카드를 고른다. 링크 복사 성공·실패는 모달 안에서 안내한다.

## 구현 계약

| 파일 | 책임 |
|---|---|
| `src/world-style-ui.ts`, `world-style.css` | 그림 카드·선택 상태·미리보기 조작·직접 조합·산책 복귀 |
| `src/world-style-presets.ts`, `world-style.ts` | 7개 조합·설명·새 사용자의 원근 기본값 |
| `src/scene/style-preview.ts` | 지연 로딩, 단일 WebGL 미리보기, 회전·재생·자원 수명 |
| `src/scene/style-preview-scene.ts` | 본편과 같은 캐릭터·건물 스타일 함수로 작은 모형 구성 |
| `src/scene/solid-person.ts` | 여섯 입체 캐릭터의 눈동자·하이라이트·웃음·손·봉제 귀 |

- 미리보기 동네는 **그림체 비교용 가상 모형**이다. 실제 단지 데이터로 소개하지 않는다. 본편의 좌표·DEM·건물 외곽선·경로·충돌 엔진은 그대로 쓴다.
- 7개 그림은 같은 Three.js 렌더러로 한 번씩 그려 Canvas2D에 복사한다. 그림마다 WebGL 컨텍스트를 만들지 않는다. 미리보기 창을 열었을 때만 본편 외에 컨텍스트 하나를 추가한다.
- 창을 닫거나 초기화에 실패하면 geometry/material/texture·그림자 렌더 타깃·observer·이벤트·RAF·WebGL 컨텍스트를 정리한다. 동적으로 불러오는 중 닫힌 창에는 생성하지 않는다.
- 자동 재생하지 않는다. 재생 중 화면 밖/비활성 탭/동작 줄이기 설정에서는 지속 렌더링을 멈춘다. 미리보기 DPR은 최대1.5다.
- 가로 드래그는 회전, 세로 터치는 스크롤이다. 회전·정면·재생 버튼도 제공한다. 본편의 이동 배속과 미리보기 걸음 시연은 별개다.
- PixelCrew 원본 아틀라스는 수정하지 않는다. 실제 입체 메시6종과 방향별 아틀라스4종 구분을 유지한다.
- 얼굴 깊이는 캐릭터별로 달라야 한다. 구슬·고무·블록에서 눈동자가 몸에 묻히지 않는지 광선 교차 테스트로 검사한다.

## 검증과 한계

- `bun run check`, `bun test`, `bun run build`: **99테스트 / 3,421 assertions / 20파일**, 실패0. Vite의 기존 큰 청크·Zod 주석 경고는 남는다.
- 새 회귀4건: 저장된 등각 선택 보존, 여섯 입체형 눈동자 가림 방지, 모형 범위/건물 재질, 다른 장면 자원과의 분리. 신규 사용자 원근 기본값도 명시 검사한다.
- 실제 Ego Chromium: 프리셋7개·서로 다른 썸네일7개, 캐릭터10선택·시점3, 저장 후 새로고침, 드래그·터치 회전·세로 스크롤·재생/정지 확인.
- 390/768/1440px × OS 밝게/어둡게6조건: 가로 넘침0, 표시된 버튼44px 미만0, 스타일 모달 axe 위반0. UI는 두 OS 선호 모두 기존 종이색 테마다.
- 미리보기 반복 열기/닫기3회·초기화 도중 의도적 실패: 컨텍스트 해제 확인. 실패 상태에서도 컨셉 선택·본편 복귀가 된다. 클립보드 거부 안내, Escape 후 스타일 버튼 포커스 복귀 확인.
- 가족·도보·4배속의 멈춘 신당역 경로(653m/10분)가 컨셉 변경 후 유지되고 재개된다. 화면 밖 및 동작 줄이기에서는 미리보기 draw 호출이 멈춘다.
- 실제 iOS/Android, Safari, 장시간 메모리 추이, 모든 조합의 미관, 공개 배포는 이번 검증 범위 밖이다. OS 비활성 탭 분기는 코드 검토만 했고 별도 실측하지 않았다.

## Claude 3D 랩과 다음 작업

병행 Claude V11의 [3D 스타일 랩](../../prototype/stylelab3d/STYLE_LAB_3D_2026-10-12.md)은 캐릭터6풍·종족4·월드5·시점4를 실험하는 별도 가상 디오라마다. 이번 기능은 **Codex 실제 단지 본편에서 스타일을 비교하고 바로 산책하는 흐름**이다. Claude 랩을 병합하거나 그 검증 수치를 Codex 결과에 더하지 않았다.

다음 후보는 랩의 2등신 주민·종족별 실루엣·셀 셰이딩을 본편 데이터/이동 계약에 맞춰 옮기는 일이다. 조형 규격과 재질 파라미터를 차용하되 시간 기반 자동 이동은 가져오지 않는다. 본편은 이동 거리 기반 애니메이션·동작 줄이기·차량/동행 모드·자원 해제 회귀를 유지한다. 실기 모바일 사용성 검증과 실제 출입구·통행 데이터 보강도 별도 과제로 남는다.
