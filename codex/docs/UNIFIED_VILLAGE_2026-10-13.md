# 한바퀴 주력 통합판

2026-10-13. 사용자 결정: 두 구현의 장단점을 합쳐 하나의 버전으로 진행한다. 주력은 **Codex의 실제 좌표 엔진 + Claude v13에서 검증한 캐릭터·상태·조작 규칙을 재구현한 단지 섬**이다. 이후 일반 기능 개발은 `codex/src/village/`를 시작점으로 한다.

## 실행

`codex/`에서 `bun install --frozen-lockfile`, `bun run build`, `bun start`.

| 화면 | 경로 | 역할 |
|---|---|---|
| **주력 통합판** | `http://localhost:5178/` | 실제 단지 섬 세 곳, 친구 꾸미기·산책·동 선택 |
| 기존 생활권 앱 | `/world.html?complex=xi` | 수첩·차량·생활권·도감·멀티플레이 보존 |
| 이전 Xi 섬 | `/island.html` | 이전 구도·팔레트 비교 |
| Codex 스타일 랩 | `/style-lab.html` | 기존 디자인 탐색 |
| Claude 프로토타입·3D 랩 | `prototype/` 별도 서버 | 역사·실험·2D 이동시간/비교 규칙 참조 |

옛 공유 URL의 `character/building/map/view/mode/party/layer/room/legacy` 파라미터는 기존 앱으로 연결한다. 단지 선택만 있는 루트 URL은 이제 통합판이다. 통합판 취향은 `complex/theme/buddy/species` URL에만 기록하며 기존 `hanbakwi-*` 저장소를 쓰지 않는다.

## 사용자 흐름

동네 선택 → 전체 섬 확인 → 건물 번호/동 선택 목록으로 살펴보기 → 주변 공간까지 걷기. 친구 따라가기로 표정과 몸을 가까이 보고, 꾸미기에서 분위기3종·친구·귀·동작을 바꾼다. 바닥 클릭/탭은 목적지 이동, 드래그는 회전, 두 손가락은 확대다. 키보드는 캔버스에 초점을 둔 뒤 WASD/방향키, 휴대폰은 직접 걷기 방향 버튼도 사용할 수 있다.

설정 열기는 걷기를 멈추며 Escape로 닫을 수 있다. 자동 산책은 켤 때만 시작한다. 도착과 정지 후에는 불필요한 프레임을 계속 만들지 않는다. 명시적으로 고른 포즈는 동작하고, 모션 줄이기 설정에서는 고정 포즈로 표시한다. 숨겨진 페이지는 프레임을 중단한다.

## 데이터와 표현

새 원자료 수집·위성 정밀 재구성은 하지 않았다. `sites.ts`가 기존 호갱노노 경계 JSON을 Zod로 읽어 원래 수집기와 같은 metre 투영을 적용한다. world JSON과 source ring은 변경하지 않는다. Xi 위성 대조는 10/12 확인 기록이며 다른 두 단지의 새 위성 대조로 확대 해석하지 않는다.

높이는 건물55%·지형35%, 나무·창문·단면은 연출이다. 라체르보 경계 안에 폭까지 들어오는 기존 OSM 길 조각은0개다. 길을 새로 발명하지 않고 모형의 충돌 없는 공간에서 산책 지점을 고른다. 산책은 약4배속이며 실제 이동시간·계단·접근성 안내가 아니다. 2D 프로토타입의 비교표/시간 규칙을 통합판 수치인 것처럼 합치지 않는다.

## 코드와 검증

- `entry.ts`: 주력/옛 공유 링크 분기. `world.html`: 기존 앱 진입점.
- `village/sites.ts`, `walker.ts`: 실제 경계와 이동 상태. `buddy.ts`: 조형·표정. `options.ts`: URL 경계 파싱.
- `village/main.ts`, `session.ts`, `shell.ts`: 로딩 수명·UI·장면 연결. `picking.ts`: 탭/드래그/핀치 구분. `route.ts`: 경로 표시.
- `island/{site,land,garden,camera,view,atmosphere,actor}.ts`: 두 화면의 공통 기반. 이전 Xi 호출은 기본값을 유지한다.
- `bun test`: **113테스트 / 12,346 assertions /22파일**. 새8개는 세 단지 경계/이동, 도착 정지, 중단·재개, 불가 목적지, 상태 전환, 캐릭터 자원 해제, 저감 모션, URL 경계를 검증한다.
- `bun run check`, `bun run build`, `bun run smoke`: 타입·빌드·4진입점/HTTP62·WebSocket6. 정적 자산 수에 따라 HTTP 건수는 바뀔 수 있다.
- `bun run lint`: 종료0. 기존 경고·정보는 별도 잔존; 새 모듈과 변경 섬 모듈의 Biome 검사 진단0.
- 브라우저: 세 단지×390/768/1440×초록/저녁18화면과 설정6화면, 가로 넘침0·axe위반0. 캐릭터/귀/6포즈·네이티브 탭 도착·키보드 해제·빠른 단지 교체·터치 회전/핀치 확인. 이는 에뮬레이션 검증이며 실기 인증이 아니다.

남은 경계: 실제 iOS/Android·Safari·장시간 발열/메모리, 실제 출입구/보행로 조사. 기존 수첩·차량·가족·생활권 기능은 보존 화면에서 사용하며, 모두 통합판에 포팅됐다고 표현하지 않는다. 다음 단계는 새 비교판을 또 만들기보다 이 주력판 안에서 사용자 사용성 피드백을 반영한다.
